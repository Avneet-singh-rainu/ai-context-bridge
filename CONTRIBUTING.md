# Contributing

This project is in its planning stage. Contribution guidelines will be added once the technical stack and development setup are confirmed.

Until then, please read [AI_Context_Bridge_Codex_Handoff.md](./AI_Context_Bridge_Codex_Handoff.md) for the product scope and ground rules.

## Pull requests

Do not push directly to main. Create a feature branch, push the branch, and open a pull request. Branch protection on main requires this.
